# the_snake

Классическая игра «Змейка» на Python и Pygame, написанная на принципах ООП.

## Правила

- Змейка постоянно ползёт и управляется стрелками на клавиатуре.
- Каждое съеденное яблоко удлиняет змейку на один сегмент.
- Через стены можно проходить: змейка появляется с противоположной стороны поля.
- Если змейка врезается сама в себя, игра начинается заново.

## Как запустить

Нужен Python 3.9 или новее.

```bash
git clone https://github.com/ban131/the_snake.git
cd the_snake
python3 -m venv venv
source venv/bin/activate        # Windows: source venv/Scripts/activate
pip install -r requirements.txt
python the_snake.py
```

Окно игры закрывается крестиком.

## Устройство кода

Вся игра находится в файле `the_snake.py`:

- `GameObject` описывает базовый игровой объект с позицией, цветом и методом `draw()`;
- `Apple` появляется в случайной свободной клетке поля;
- `Snake` хранит сегменты, направление движения и умеет двигаться, расти и сбрасываться;
- `handle_keys()` обрабатывает нажатия клавиш;
- `main()` запускает игровой цикл.
